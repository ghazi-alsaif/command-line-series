# الإبلاغ عن مشاكل أمنية · Security policy

## العربية

إذا وجدت مشكلة أمنية في أدوات المشروع أو إعداداته، فلا تنشر تفاصيلها
في Issue عام. استخدم
[بلاغًا أمنيًا خاصًا](https://github.com/ghazi-alsaif/command-line-series/security/advisories/new)
مع خطوات إعادة المشكلة وأي أثر متوقع.

هذا المشروع عبارة عن سلسلة كتب ومواد تعليمية، ولا يقدم خدمة شبكية أو نظام مصادقة. لذلك تتركز البلاغات الأمنية المتوقعة على الروابط، الملفات المرفقة، أو الأدوات البرمجية.

## English

If you discover a security issue in the project tools or configuration, do not
disclose it in a public Issue. Submit a
[private security report](https://github.com/ghazi-alsaif/command-line-series/security/advisories/new)
with reproduction steps and the expected impact.

This repository is primarily a book series and educational material. It does not provide a network service or authentication system, so security reports are most likely to concern links, distributed files, or helper tools.
