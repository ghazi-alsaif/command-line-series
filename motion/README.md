# فيديو سلسلة سطر الأوامر · Motion Promo

فيديو ترويجي عمودي لسلسلة «سطر الأوامر»، مبني برمجيًا بـ
[Remotion](https://www.remotion.dev/) + React + TypeScript، ويستعمل أصول
المستودع نفسها: الأغلفة الرسمية، هوية السلسلة، والخطوط المثبّتة في `fonts/`.

| | |
|---|---|
| الأبعاد | 1080 × 1920 (9:16 عمودي) |
| المعدّل | 30 إطارًا/ثانية |
| المدة | ≈ 41 ثانية (تُحسب من `src/timeline.ts`) |
| الترميز | H.264 · yuv420p · CRF 16 · صوت AAC |

## التشغيل

يتطلب Node.js 18+ و ffmpeg (للنسخة المصغّرة فقط).

```bash
cd motion
npm install
```

### المعاينة (أمر واحد)

```bash
npm run preview
```

يفتح Remotion Studio في المتصفح لمعاينة الفيديو إطارًا إطارًا وتعديله حيًّا.

### الرندر النهائي (أمر واحد)

```bash
npm run render
```

الناتج: `motion/out/command-line-series-promo-vertical.mp4`

نسخة معاينة خفيفة (540×960) بعد الرندر:

```bash
npm run render:preview
```

الناتج: `motion/out/command-line-series-promo-preview-540p.mp4`

> في بيئة بلا إنترنت، حدّد متصفح Chrome محليًا:
> `REMOTION_BROWSER=/path/to/chrome-headless-shell npm run render`

### إطارات للفحص

```bash
npm run stills            # نقاط افتراضية
npm run stills -- 150 600 # إطارات بعينها
```

تُحفظ في `motion/out/stills/`.

## من أين تأتي البيانات؟

`npm run preview` و `npm run render` يشغّلان أولًا `scripts/prepare-assets.mjs`، وهو:

1. **يقرأ `README.md` في جذر المستودع** ويستخرج أسماء الكتب وترتيبها
   وموضوعاتها وعدد صفحات كل كتاب، و**مجموع الصفحات** (السطر «المجموع … صفحة»)،
   والشعار «من الصفر إلى فهم الآلة»، وسطر «المتطلّب الوحيد…»، ورابط الموقع،
   ثم يكتبها في `src/data/generated.json`. عدّل README يتعدّل الفيديو.
2. ينسخ الخطوط المطلوبة من `fonts/` إلى `public/fonts/` (تُحمّل محليًا، بلا CDN).
3. ينسخ الهوية من `docs/readme-brand/` إلى `public/brand/`.

## الأصول

| الأصل | المكان | ملاحظة |
|---|---|---|
| الأغلفة العشرة | `public/covers/*.jpg` | صفحة الغلاف الرسمية لكل كتاب مرندرة من مصدرها بـ Typst (1000×1419). مطابقة لـ `docs/readme-covers/` لكن بدقة أعلى تكفي لإطار 1080×1920. لا قصّ ولا تعديل. |
| هوية السلسلة | `../docs/readme-brand/` | `series-mark.png` و `series-identity.png` كما هما |
| الخطوط | `../fonts/` | IBM Plex Sans Arabic · Noto Kufi Arabic · JetBrains Mono |
| المؤثرات الصوتية | `public/sfx/*.mp3` | مركّبة رياضيًا بـ ffmpeg (`scripts/make-sfx.sh`) — لا تسجيلات ولا مواد مرخّصة |

لإعادة توليد الأغلفة من مصادر الكتب (يتطلب Typst بالإصدار في `TYPST_VERSION`):

```bash
TYPST=~/.local/bin/typst node scripts/prepare-assets.mjs --refresh-covers
```

إن غابت `public/covers/`، يرجع السكربت تلقائيًا إلى `docs/readme-covers/` (376×533، دقة أقل).

## التعديل

### النصوص

- أسماء الكتب وموضوعاتها والصفحات: **من `README.md`** مباشرة.
- باقي العبارات (أربعُ نوافذ، اقتباس «رُوحٌ في الآلة»، مراحل السكة…): `src/data/copy.ts`
  — وبجانب كل عبارة مصدرها في المستودع.
- الأوامر الظاهرة مع الكتب 7–10 ولون كل غلاف: `src/data/books.ts`.

### المدد

كل المدد بالإطارات في `src/timeline.ts` (30 إطارًا = ثانية):

```ts
export const BEATS = {
  hook: 132,          // الافتتاح
  windowsSlot: 72,    // كل كتاب من البدايات الأربع
  windowsGroup: 90,   // الأربعة معًا
  practiceSlot: 78,   // الطرفيّةُ بالممارسة
  storySlot: 112,     // رُوحٌ في الآلة (أهدأ)
  realLead: 6,
  realSlot: 62,       // كل كتاب من 7–10 (أسرع)
  hero: 190,          // الكتب العشرة
  outro: 150,         // الخاتمة
};
```

المدة الكلية ومواضع المؤثرات الصوتية وألوان الخلفية تُحسب تلقائيًا من هذه القيم.

### الألوان والحركة

`src/theme.ts`: ألوان الهوية (من `lib/theme.typ`)، المنطقة الآمنة، ومنحنيات
الحركة الموحّدة (دخول/خروج/كاميرا) التي يستعملها الفيديو كله.

## العربية و RTL

- كل نص عربي عقدة واحدة في DOM بـ `dir="rtl"` و `unicode-bidi: isolate` —
  لا تقسيم إلى حروف، فالوصل والتشكيل سليمان.
- الظهور بمسح متدرّج (`mask-image`) يتقدّم من اليمين إلى اليسار على السطر كاملًا.
- الكتابة حرفًا حرفًا مقصورة على أوامر الطرفية اللاتينية (`./build.sh`، `git init`…).

## المشاهد

1. **الافتتاح** — `$ ./build.sh` ثم «من الصفر إلى فهم الآلة» وهوية السلسلة، والأغلفة تعبر العمق خلفها.
2. **البدايات الأربع** — لينكس · ماك · ويندوز · BSD، ثم الأربعة معًا: «أربعُ نوافذ. حِرفةٌ واحدة.»
3. **الممارسة والحكاية** — «الطرفيّةُ بالممارسة» ثم «رُوحٌ في الآلة» بحركة أهدأ وخط زمني يبدأ من 1969، واقتباس من توطئته.
4. **العالم الحقيقي** — سكة الأتمتة ← الخوادم ← الشبكات ← المشروعات، مع أمر حقيقي من متن كل كتاب.
5. **الكتب العشرة** — تكوين بترتيب السلسلة (4 · 2 · 4)، «10 كتب» وعدّاد الصفحات من README.
6. **الخاتمة** — تنفتح الشاشة على ورق الكتب الدافئ، هوية السلسلة الرسمية، المتطلّب الوحيد، الاسم والروابط.

# الفيديو الثاني: «الهبوط» · Descent

لقطة واحدة متصلة بلا قطع: يُكتب `cd /` (اذهب إلى الجذر)، فينبت شعار الطرفية جذورًا،
وتهبط الكاميرا داخل الجذر من الشعار حتى طرفه، وتمرّ بالكتب العشرة بترتيبها.
عدّاد «العمق» يقيس الهبوط **بالصفحات** حتى يبلغ مجموع السلسلة. عند الطرف ينتهي الجذر
بمؤشر طرفية، ثم تنسحب الكاميرا فتظهر الشجرة كلها: الكتب العشرة معلّقة على جذور الشعار.
وآخر إطار يطابق الأول، فيدور الفيديو في حلقة بلا خياطة ظاهرة.

| | |
|---|---|
| الأبعاد | 1080 × 1920 · 30fps |
| المدة | 44 ثانية = 22 مازورة على 120 BPM |
| الصوت | موسيقى تصويرية ومؤثرات مركّبة رياضيًا (بلا عيّنات ولا مواد مرخّصة) |

```bash
npm run render:descent          # → out/command-line-series-descent-vertical.mp4
npm run render:descent:preview  # نسخة خفيفة 540p
npm run music                   # إعادة توليد الموسيقى (يتطلب python3 + numpy + scipy)
```

### الفكرة البصرية

| المقطع | ما يحدث | المعنى |
|---|---|---|
| الافتتاح | `$ cd /` ثم «من الصفر إلى فهم الآلة»، والشعار ينبت جذورًا مع الضربة الأولى | `/` هو الجذر؛ وعنوان الكتاب الأول «إلى الجَذر» |
| الكتب 1–4 | أربعة خيوط مضفورة بألوان الأغلفة الأربعة | أربع نوافذ |
| الملتقى | الخيوط الأربعة تلتقي جذعًا واحدًا: «أربعُ نوافذ. حِرفةٌ واحدة.» | One craft, every system |
| الكتاب 6 | طبقة 1969، والحركة تهدأ، واقتباس من التوطئة بإيقاع آلة كاتبة | الحكاية |
| الكتب 7–10 | الجذر يصير مسار دارة إلكترونية (انعطافات 45°)، وأوامر حقيقية تُكتب | من الأمر إلى الأنظمة |
| الطرف | الجذر ينتهي بمؤشر: «كل كتاب يبدأ من الصفر»، ونبضة صمت قبل الانفجار | |
| الشجرة | الكتب العشرة على جذور الشعار، كل غلاف يهبط على نغمته | |
| الخاتمة | الشعار ينفتح ورقًا دافئًا، ثم ينغلق على المؤشر | حلقة |

### الصوت مرتبط بالصورة إطارًا بإطار

`src/descent/plan.ts` هو المصدر الوحيد للتوقيت: حركة الكاميرا، لحظات الهبوط، الكتابة.
`scripts/export-plan.ts` يصدّره JSON، و `scripts/score.py` يبني منه الموسيقى:

- **نَفَس الهواء** يُشتق من سرعة الكاميرا المحسوبة لكل إطار (ثلاث نطاقات ترددية تتبع السرعة).
- **كل حرف** يُكتب على الطرفية = نقرة مفتاح في الإطار نفسه.
- **لكل كتاب نغمة** من سُلّم ري الصغير، صاعدة مع العمق؛ تُعزف عند الهبوط عليه، ثم تُعزف العشر لحنًا حين تجتمع الكتب.
- الإيقاع 120 BPM = 15 إطارًا للنبضة: كل هبوط وكل قطع على رأس نبضة.
- التدرج: نبض قلب ← أربيجيو ← هدوء وآلة كاتبة ← إيقاع كامل ← مُصعِّد وصمت ← انفجار ← خاتمة دافئة ← نبض القلب نفسه الذي بدأ به.

# الفيديو الثالث: «رف السلسلة» · Shelf (ثلاثي الأبعاد)

مشهد ثلاثي الأبعاد حقيقي (Three.js عبر `@remotion/three`): مجسمات للكتب العشرة بإضاءة وظلال.

| | |
|---|---|
| الأبعاد | 1080 × 1920 · 30fps · 42 ثانية |
| الرندر | WebGL برمجي (`--gl=swangle`) فيعمل بلا كرت شاشة؛ على جهاز فيه GPU جرّب `--gl=angle` لسرعة أكبر |

```bash
npm run render:shelf          # → out/command-line-series-shelf-3d-vertical.mp4
npm run render:shelf:preview  # نسخة خفيفة 540p
npm run music:shelf           # إعادة توليد الموسيقى (python3 + numpy + scipy)
TYPST=~/.local/bin/typst npm run assets:3d   # إعادة توليد الأصول ثلاثية الأبعاد من مصادر الكتب
```

### كل ما في المشهد من المستودع

| العنصر | المصدر |
|---|---|
| الغلاف الأمامي | صفحة الغلاف الرسمية لكل كتاب (`public/covers/`) |
| الغلاف الخلفي | **آخر صفحة** من كل كتاب مرندرة بـ Typst (`public/3d/back-*.jpg`) |
| الكعب | يُصفّ بـ Typst بخط Noto Kufi Arabic: عنوان الكتاب ورقمه بلون عنوان غلافه |
| **السماكة** | محسوبة من **عدد صفحات** كل كتاب في README (ورق ≈ 0.1 مم للورقة + غلافان)، مضخّمة 1.5× بالتناسب نفسه؛ فارتفاع البرج هو مجموع صفحات السلسلة فعلًا |
| الصفحات الداخلية | الصفحات 13–15 من الكتاب الأول: افتتاحية «الجزء الأول: الأساسات» ثم «الفصل 1: ما هي الطرفية؟» |

### المشاهد

1. `$ ls ~/books` ويظهر ناتجه: مجلدات الكتب العشرة الحقيقية في `books/`.
2. مصباح يشتعل بوميض، وشعاع ضوء حجمي وغبار يسبح فيه.
3. الكتب تسقط واحدًا بعد الآخر على رأس كل نبضة، فيُبنى **برج** تتبعه الكاميرا صعودًا وتدور حوله لتظهر الكعوب.
4. البرج كاملًا: «10 كتب · 3,482 صفحة · سماكة كل كتاب هنا بعدد صفحاته».
5. الكتب ترتفع (الأعلى أولًا) إلى **لولب** يدور، والكتاب الأول في أسفله والعاشر في أعلاه، والكاميرا تصعده كدرج: «كل كتاب يبدأ من الصفر، ويعطي القارئ مفتاحًا يفتح به الباب التالي».
6. الكتاب الأول يتقدم، ينفتح غلافه على مفصل، وتنقلب ورقة بانحناء حقيقي، فتقترب الكاميرا حتى تُقرأ صفحة «ما هي الطرفية؟».
7. الكاميرا تدخل في ورق الصفحة، فتصير الشاشة ورقًا دافئًا تظهر عليه هوية السلسلة والروابط.
